# NavisWORLD Profile Evolution Report

## Mission

Audit → preserve → cosmify → animate → connect → organize → delight → verify.

## Audited

The update was designed against the current profile structure and preserves the existing public identity, Beast Box entry point, GitHub Sponsors, Buy Me a Coffee, project constellation, CST boundary language and open-source licensing links.

## Preserved

The update does not modify:

- `.github/FUNDING.yml`
- `LICENSE`
- `OPEN_SOURCE_SCOPE.md`
- `OPEN_SOURCE_ECOSYSTEM.md`

The README retains the core boundary:

`MODEL ≠ MEMORY ≠ STATE ≠ AUTHORITY`

## Redesigned

The profile now reads as a guided workshop rather than a control-deck list. It includes a warm cosmic workshop hero, a recurring Spark Beast, a continuity diagram, model garden, Lost COSMOS game shelf, CST observatory, simulation/measurement bench, device lab and support shelf.

## Animation

`assets/light-bringer.svg` uses small opacity/translation animation only. It includes a `prefers-reduced-motion` media rule that freezes those animations; the composition remains complete when animation is disabled.

## Scientific boundaries

The README explicitly separates simulator, seeded, measured and hardware/QPU categories, and states that:

- computational `12D` does not prove physical dimensions,
- continuity does not prove consciousness,
- visualization does not prove experiment,
- seeded generation does not become hardware measurement through presentation.

## Creature metrics

`assets/creature-telemetry.svg` is labeled `EXAMPLE CREATURE TELEMETRY` and is based on the supplied Spark UI capture. The values `focus 18`, `calm 8`, `spark 94` are labeled simulated, not live EEG or a public backend feed.

## Model garden

RAWRPHØS, PHOS, SAMGO, MUSE and SOL are presented as NavisWORLD ecosystem identities with status language scoped to what the profile can support. MUSE is explicitly distinguished from the Muse EEG/headband connector.

## Device lab

The README describes watch/handheld/puck surfaces as bounded clients. A watch can render a small creature snapshot and send input events while the phone/local host keeps the ledger, policy and optional inference. Custom hardware remains labeled concept until a prototype supports stronger wording.

## Accessibility

Every major README image has meaningful alt text. Critical technical information remains in text. The primary animated SVG has a static reduced-motion fallback and is readable when animation is frozen.

## Verification

`python scripts/check_profile.py` validates:

- required files,
- SVG XML,
- local image paths,
- important links in the README,
- FUNDING.yml wiring,
- scientific-boundary phrases,
- basic secret/script patterns,
- raster file signatures,
- non-empty HTML image alt text.

GitHub Actions runs this check on pull requests and pushes to `main`.
